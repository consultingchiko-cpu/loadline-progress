# Security Policy

## Supported versions

Security fixes are applied to the latest published minor version. The `0.2.x` line is currently supported while the package remains in pre-1.0 development.

## Reporting a vulnerability

Please do not disclose security issues in a public GitHub issue. Use GitHub's private vulnerability reporting for this repository when available, or open a minimal issue asking for a private contact channel without including exploit details.

Include:

- affected version;
- a clear description and impact;
- reproducible steps or a minimal proof of concept;
- any suggested mitigation.

Please allow reasonable time for triage before public disclosure. Loadline is a browser-side library; reports involving the demo, build tooling, or development dependencies should identify which surface is affected.
